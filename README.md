# BodyFit Fitness Centre

Welcome to the BodyFit Fitness Centre web application repository!

## Overview
BodyFit Fitness Centre is a modern, responsive single-page web application designed for gym members and visitors.

## Features
- **Hero Section**: Live open/closed status & quick action CTA buttons.
- **Facilities & Equipment**: Showcasing gym amenities.
- **Membership Plans**: Clear pricing tiers (Basic, Standard, Premium).
- **Appointment & Class Booking**: Online booking integration with LocalStorage persistence and WhatsApp alerts.
- **Trainer Profiles & Schedules**: Find trainers and view weekly timetables.
- **Admin Dashboard**: Easily manage bookings, trainers, and plans.

## Tech Stack
- **Frontend**: React, Tailwind CSS
- **State & Storage**: React Context + Browser LocalStorage API
- **Icons & UI Components**: Lucide React, Framer Motion

## Getting Started

### Prerequisites
Make sure you have Node.js installed on your machine.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/dontcodejunaid/BodyFit.git
   ```
2. Navigate to the project directory:
   ```bash
   cd BodyFit
   ```
3. Install dependencies (once dependencies are added):
   ```bash
   npm install
   ```
